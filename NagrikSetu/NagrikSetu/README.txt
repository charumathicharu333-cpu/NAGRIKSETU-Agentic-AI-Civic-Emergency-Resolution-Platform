NagrikSetu Civic Operations Demo

Open index.html in a modern browser. The dashboard is self-contained and has no build or installation step.

The page includes interactive response simulation, incident brief, explainability, war-room and prevention panels, citizen report clustering, resolution challenge actions, mobile navigation and a responsive situation map.

All values, incidents, agent actions, forecasts, impact counts, and team estimates are illustrative demo data. This is not a live dispatch system and must not be used to make real emergency decisions.
